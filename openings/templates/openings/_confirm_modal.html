{% comment %} Confirmation dialog for close / reopen / delete. Shown by HTMX inside #modal, or inside confirm_page.html for an ordinary GET. Loading it never changes data: only the POST form below does. Cancel is a native
, which the browser handles by closing the dialog, with no request sent. The `open` attribute (not the modal-open class) is what makes it visible, so closing the dialog really hides it. {% endcomment %}
{% if action == "close" %}

Close opening {{ opening }}?

This opening will stop accepting new applications. Existing applications are not changed, and you can reopen it later.

{% elif action == "reopen" %}

Reopen opening {{ opening }}?

This opening will accept new applications again.

{% else %}

Delete opening {{ opening }}?

This will permanently delete the opening. Its skills are kept for other openings. This cannot be undone.

To stop accepting applicants but keep the record, close it instead.
